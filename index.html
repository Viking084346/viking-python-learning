Python Code Adventure

เรียนเขียนโค้ด Python ด้วยการพานักผจญภัยเดินไปให้ถึงธง ฝึกวันละนิด แล้วสะสมความต่อเนื่องไปเรื่อย ๆ

  • 5 ด่านผจญภัยลำดับคำสั่ง การเลี้ยว การวนซ้ำ และเงื่อนไข
  • ความต่อเนื่องและแต้ม streakเลือกเป้าหมาย 10 วัน 20 วัน หรือกำหนดเอง
  • สถิติการเรียนดูวันที่เรียน ดาว คะแนน และด่านที่ยังติดขัด
  • แจ้งเตือนตามเวลาของคุณเลือกเวลาและวันที่ต้องการให้เตือน

ถ้าเห็นข้อความนี้ แปลว่าระบบยังไม่ทำงาน ให้ดาวน์โหลดไฟล์แล้วเปิดด้วย Chrome, Edge หรือ Safari
